# راهنمای نصب گپ‌بان

## پیش‌نیازها
- وردپرس ۶٫۵ یا جدیدتر
- PHP نسخهٔ ۸٫۱ یا جدیدتر (۸٫۲ به بالا توصیه می‌شود) با افزونه‌های `sodium`، `mbstring` و `fileinfo`؛ افزونهٔ `intl` اختیاری است و برای تاریخ شمسی در فایل‌های خروجی به کار می‌رود.
- MySQL ۵٫۷ یا MariaDB ۱۰٫۴ به بالا با موتور InnoDB
- دسترسی HTTPS خروجی سرور به `tapi.bale.ai`
- برای وب‌هوک: نشانی سایت با HTTPS

## نصب
۱. در پیشخوان وردپرس به «افزونه‌ها ← افزودن ← بارگذاری افزونه» بروید و فایل `gapban.zip` را بارگذاری کنید.
۲. افزونه را فعال کنید. در وردپرس چندسایته، گپ‌بان را در هر سایت جداگانه فعال کنید؛ فعال‌سازی شبکه‌ای پشتیبانی نمی‌شود.
۳. به منوی «گپ‌بان ← راه‌اندازی و اتصال» بروید و گام‌ها را به ترتیب انجام دهید (راهنمای ربات بله را ببینید).
۴. کرون سرور را مطابق «راهنمای کرون» تنظیم کنید.

## تنظیمات پیشنهادی در wp-config.php
```php
define( 'GAPBAN_ENCRYPTION_KEY', 'یک رشتهٔ تصادفی دست‌کم ۳۲ نویسه‌ای' ); // رمزنگاری توکن مستقل از کلیدهای وردپرس
define( 'GAPBAN_STORAGE_DIR', '/home/USER/gapban-files' );             // نگهداری فایل‌ها بیرون از پوشهٔ عمومی وب
// define( 'GAPBAN_BALE_TOKEN', '123:ABC…' );                           // اختیاری: توکن فقط در پیکربندی
```

## بدون ربات هم کار می‌کند
تا وقتی ربات بله وصل نشده باشد، گفتگوها فقط در «صندوق گفتگوها»ی وردپرس ذخیره می‌شوند و از همان‌جا پاسخ داده می‌شوند.
