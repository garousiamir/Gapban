# رفع اشکال

| نشانه | علت محتمل | راه‌حل |
|---|---|---|
| «دسترسی به بله ممکن نشد» | سرور به tapi.bale.ai دسترسی خروجی ندارد | از میزبان بخواهید HTTPS خروجی به tapi.bale.ai را باز کند |
| «بله توکن ربات را رد کرد» | توکن اشتباه یا باطل شده | توکن تازه را از ‎@BotFather بگیرید و دوباره ذخیره کنید |
| پیام‌ها در «در انتظار ارسال» می‌مانند | پردازشگر اجرا نمی‌شود | کرون را تنظیم کنید یا «صف ارسال ← اجرای پردازشگر» را بزنید |
| «گفتگو پیدا نشد» از بله | ربات عضو گروه نیست یا شناسه غلط است | ربات را به گروه اضافه کنید و دوباره کد اتصال بفرستید |
| اپراتور پاسخ می‌دهد ولی به سایت نمی‌رسد | ریپلای نکرده، حساب متصل نیست یا دریافت کار نمی‌کند | پیام ربات در بله را بخوانید؛ «صف ارسال ← به‌روزرسانی‌های اخیر بله» را بررسی کنید |
| وب‌هوک ثبت نمی‌شود | سایت HTTPS ندارد | HTTPS را فعال کنید یا از دریافت دوره‌ای استفاده کنید |
| «نامطمئن» در صف | قطع شدن به‌علت مهلت پس از ارسال | پیش از «تلاش دوباره» گروه بله را بررسی کنید تا پیام تکراری نشود |
| «از بیرون قابل دسترسی است» برای فایل‌ها | nginx فایل .htaccess را نمی‌خواند | قاعدهٔ nginx را اضافه کنید یا GAPBAN_STORAGE_DIR را تنظیم کنید: `location ~* /wp-content/uploads/gapban-private-[a-z0-9]+/ { deny all; }` |
| دکمهٔ گفتگو روی نوار پایین قالب می‌افتد | نوار ثابت | انتخابگر نوار را در «ظاهر ابزارک ← عناصری که نباید پوشانده شوند» وارد کنید |
| ابزارک روی صفحه‌های کش‌شده نمایش داده نمی‌شود | افزونهٔ بهینه‌سازی اسکریپت را حذف یا ترکیب کرده | `gapban-widget` را از ترکیب یا تأخیر مستثنا کنید؛ پیکربندی صفحه هیچ دادهٔ شخصی ندارد و کش کردن آن امن است |

برای جزئیات فنی «صف ارسال و عیب‌یابی ← بررسی سیستم» را ببینید.
