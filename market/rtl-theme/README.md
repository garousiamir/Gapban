# بستهٔ انتشار گپ‌بان در راست‌چین

همهٔ چیزهایی که برای فرم «ارسال محصول» راست‌چین لازم است، در این پوشه و پوشهٔ `release/` آماده شده است. **لایسنس هنوز اضافه نشده** (طبق تصمیم شما، بعداً). پس از افزودن لایسنس، فقط فرمان بخش «ساخت دوباره» را اجرا کنید تا فایل‌ها به‌روز شوند.

## فایل‌ها و جای هر کدام در فرم

| فرم راست‌چین | فایل |
|---|---|
| فایل محصول (دانلود خریدار) | `release/gapban-rtl-theme-1.0.0.zip` |
| عنوان، توضیح کوتاه، برچسب‌ها، دسته | `product-page.md` |
| توضیحات کامل (ویرایشگر، حالت HTML) | `product-description.html` |
| تصویر شاخص / کاور | `images/cover-1600x900.jpg` |
| آیکن / تصویر کوچک | `images/icon-512.png` (یا `images/square-1080.jpg`) |
| گالری تصاویر (به همین ترتیب) | `images/gallery-01-site.jpg` … `images/gallery-08-features.jpg` |
| ویدیوی معرفی (آپارات) | `video/gapban-rtl-theme-1080p.mp4`، پوستر `video/poster.jpg` |
| تغییرات نسخه | بخش «تغییرات نسخه‌ها» در `product-page.md` |

> **ابعاد تصاویر:** ابعاد دقیق تصاویر را در پنل فروشندگی راست‌چین ببینید؛ از این محیط به سایت راست‌چین دسترسی نبود. اگر اندازهٔ دیگری لازم بود، اندازه را در `tools/market-images.mjs` عوض کنید و دوباره بسازید. چیدمان‌ها با هر اندازهٔ نزدیک به همین نسبت‌ها درست می‌مانند.

### ویدیو برای صفحهٔ محصول
- `video/gapban-rtl-theme-1080p.mp4` همان ویدیوی ۴۵ ثانیه‌ای است، با یک تفاوت: صحنهٔ قیمت **بدون نام رقبا** است و فقط سه کارت دارد («خرید یک‌باره»، «۰ تومان اشتراک ماهانه»، «سایت خودتان»).
- مارکت‌ها معمولاً نام بردن از سرویس‌های دیگر را در صفحهٔ محصول نمی‌پذیرند. نسخهٔ دارای جدول مقایسه با رایچت و گفتینو (`marketing/out/…`) را فقط در کانال‌های خودتان (اینستاگرام و سایت) استفاده کنید.

**عنوان آپارات:** گپ‌بان | چت آنلاین وردپرس با پاسخ‌گویی از داخل بله

**توضیح آپارات:**
مشتری روی سایت پیام می‌دهد و شما در گروه بله فقط «ریپلای» می‌کنید؛ پاسخ همان لحظه روی سایت می‌رسد.
افزونهٔ گپ‌بان: چت آنلاین کاملاً فارسی، صندوق گفتگوی وردپرس، پیام خودکار، گزارش و رضایت مشتری، بدون اشتراک ماهانه.
«بله» نام تجاری متعلق به صاحب آن است؛ گپ‌بان افزونه‌ای مستقل و سازگار با پیام‌رسان بله است.

**برچسب‌های آپارات:** چت آنلاین، وردپرس، بله، پشتیبانی آنلاین، افزونه وردپرس

## چک‌لیست پیش از ارسال

### ⛔ لازم پیش از فروش (از این محیط ممکن نبود)
- [ ] **آزمون واقعی با بله.** دسترسی به `tapi.bale.ai` از اینجا مسدود بود و رفت‌وبرگشت واقعی پیام هرگز اجرا نشده است. روی هاست خودتان:
  1. ربات بسازید، توکن را ثبت کنید و گروه را وصل کنید.
  2. از سایت پیام بدهید و ببینید پیام در گروه برسد.
  3. روی پیام ریپلای کنید و ببینید پاسخ روی سایت برسد.
  4. یک بار با وب‌هوک و یک بار با دریافت دوره‌ای امتحان کنید.
  5. ارسال عکس و فایل را در هر دو جهت امتحان کنید.
  6. فرمان‌های `/claim` و `/close` را امتحان کنید.

  هر مورد را با جدول «قابلیت‌های بله» در صفحهٔ راه‌اندازی تطبیق دهید و اگر خطایی دیدید، گزارشش را بفرستید تا درستش کنم.
- [ ] **آزمون روی آخرین نسخهٔ وردپرس.** آزمون‌ها روی وردپرس ۶٫۵٫۵ انجام شده است؛ دانلود نسخهٔ جدیدتر از این محیط ممکن نبود. بازبین‌های مارکت معمولاً روی آخرین نسخه نصب می‌کنند. روی آخرین نسخهٔ وردپرس با PHP ۸٫۲ یا ۸٫۳ و `WP_DEBUG` روشن نصب کنید و ببینید هیچ خطا یا اخطاری نمایش داده نشود. بعد مقدار `Tested up to` را در `gapban/readme.txt` به همان نسخه تغییر دهید.
- [ ] **مخزن گیت‌هاب را خصوصی کنید.** `github.com/garousiamir/Gapban` الان **عمومی** است و کد کامل و فایل‌های نصبی را هر کسی رایگان دانلود می‌کند. از Settings ← Danger Zone ← Change visibility ← Private.

### پیشنهادی
- [ ] **نام فروشنده:** فیلد `Author` در `gapban/gapban.php` الان «گپ‌بان» است. اگر راست‌چین نام حساب فروشنده را می‌خواهد، همان را بنویسید.
- [ ] **گزارش با داده:** اسکرین‌شات «گزارش‌ها» با دادهٔ آزمایشی کم گرفته شده است. پس از چند روز استفادهٔ واقعی، با `marketing/promo/capture.cjs` دوباره بگیرید تا نمودارها پرتر دیده شوند.
- [ ] **دموی آنلاین:** اگر راست‌چین برای افزونه پیش‌نمایش زنده می‌خواهد، یک وردپرس آزمایشی با گپ‌بان فعال بالا بیاورید. تا آن موقع ویدیو و گالری کافی است.
- [ ] **لایسنس:** پس از افزودن سیستم لایسنس راست‌چین، شمارهٔ نسخه را در `gapban/gapban.php` (هر دو جا)، `gapban/readme.txt` و `package.json` بالا ببرید و بسته را دوباره بسازید.

## ساخت دوباره
```
node tools/package-rtl-theme.mjs                                   # افزونه + راهنما + بستهٔ خریدار
NODE_PATH=<global node_modules> node tools/market-images.mjs       # کاور، آیکن، گالری
NODE_PATH=<global node_modules> node marketing/promo/render.mjs /tmp/framesM --scene=marketing/promo/v2/scene.html --timeline=marketing/promo/v2/timeline.json --market
```
بعد ویدیو را با همان فرمان ffmpeg که در `marketing/README.md` آمده بسازید. توضیحات HTML از `product-page.md` ساخته شده است؛ اگر متن را عوض کردید، HTML را هم به‌روز کنید.
